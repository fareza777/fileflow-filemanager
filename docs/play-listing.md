```
FileFlow is a file manager for people whose Downloads folder has become a jungle.

Browse, copy, move, rename, share and delete like any good file manager — then let Auto Rules keep everything in its place, without lifting a finger.

AUTO RULES — SET IT ONCE, STAY TIDY
Write a rule in plain terms: "PDFs from WhatsApp go to Documents/Work", "screenshots older than 90 days move to Archive", "APKs older than 30 days collect in Review". Rules run on a schedule you choose — daily at 21:00, weekly on Sunday, or on demand.

Nothing moves by surprise:
• Preview shows the exact list of files and destinations before anything happens
• Every run is logged with the file count and size
• One tap undoes an entire run, restoring every file to where it was
• Each rule can be switched off without losing its settings

SMART RENAME — FIX NAMES YOU CANNOT SEARCH
Files called IMG_20230101_120000.jpg, a3f9c1b2d4e5.pdf or "report (1) (1).pdf" are impossible to find later. FileFlow reads them, recovers the date hidden inside, removes download-manager noise, and proposes a name you can actually search — with a reason shown next to every suggestion. Nothing is renamed until you say so.

A CALENDAR OF YOUR FILES
Ever wonder what came in on a particular day? Open Calendar and every month is laid out with the days that received files shaded by how busy they were. Tap any day to see exactly what arrived — photos as a gallery, documents as a list — then move, share or delete from there. Something not showing up? A full storage scan finds the files Android's index never recorded.

CLEAN UP WITHOUT FEAR
• Duplicate finder: compares by content, keeps the original, removes the copies
• Large files: every heavyweight on your storage, sorted by size
• Junk cleaner: empty files, leftover temp data, crash logs, stale installers
• Storage analyzer: what is really eating your space, by category and by folder
• Trash: deletions wait 30 days before they are gone for good

FAST, AND PRIVATE BY DESIGN
• No account. No sign-up. No cloud. No analytics.
• Your files never leave your phone — there is no server to send them to
• Works completely offline; browsing and rules need no connection at all
• Material 3 design with full dark mode and wallpaper-based colours
• Ads are limited to three screens and never appear in the browser, search or preview

FIND ANYTHING, INSTANTLY
Search by name, type, size or date. Tap the APK filter to see every installer on the device, select them all and delete them in one go. Any search can be turned into a rule with a single tap.

WHAT FILEFLOW NEEDS
File management requires the "All files access" permission, the same one every file manager uses. It is used only to read and change files you point it at. Nothing is uploaded, ever.

Built for Android 8.0 and newer.
```

## 2. "All files access" declaration

Play Console → App content → **All files access** → *Permitted use*.

Select: **File management**

**Explanation to paste:**

```
FileFlow is a file manager. Its core, documented purpose is to let a person
browse, organise, and clean up the files on their own device.

The MANAGE_EXTERNAL_STORAGE permission is required for the app's primary
functions, all of which are listed on the store listing:

1. Browsing and searching every folder on internal storage and any mounted SD
   card, including folders outside the app-specific directory.
2. Copying, moving, renaming, and deleting files and folders the user selects.
3. Scanning storage to find duplicate files, large files, and disposable junk
   (empty files, leftover temp data, stale installers) so the user can review
   and remove them.
4. Running user-authored "Auto Rules" that move matched files into folders the
   user chose, either on demand or on a schedule the user set, including while
   the app is in the background.

None of these operations are achievable through the Storage Access Framework:
SAF cannot provide a unified, indexed view of the filesystem, cannot run
unattended on a schedule, and cannot perform the storage-wide duplicate and junk
scans that are the app's distinguishing features. The app is a file manager, not
a utility that happens to touch storage as a side effect.

FileFlow performs no data collection and transmits no file data anywhere. All
processing happens on the device. The only network traffic is Google AdMob, used
for the banner ads described in the privacy policy.

The app also declares READ_EXTERNAL_STORAGE and WRITE_EXTERNAL_STORAGE with
maxSdkVersion 29 for the same functionality on Android 9 and older, and
POST_NOTIFICATIONS (optional) to report the result of a scheduled rule.
```
